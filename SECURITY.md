# Security policy

## Supported versions

Only the [latest release](https://github.com/grayfvll01/stat-wisp/releases/latest) receives fixes. In-app updates deliver them automatically unless turned off.

## Report a vulnerability

Please report privately through [GitHub security advisories](https://github.com/grayfvll01/stat-wisp/security/advisories/new). Do not open a public issue.

Include the affected version, steps to reproduce, and the impact. You will receive an acknowledgement as soon as possible, and a fix will be released for confirmed issues.

## Scope

Stat Wisp runs as the current user. Its only network activity is the update check and download from this repository's GitHub releases, verified by size and SHA-256. Reports about the updater, installer, DLL loading, and settings handling are especially welcome.
